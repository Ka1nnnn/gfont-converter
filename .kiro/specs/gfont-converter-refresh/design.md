# GFont Converter — дизайн UI и публичного релиза

## Подход

Сохранить существующую компоновку приложения: панель сведений, сетку глифов, карточку выбранного глифа, журнал и строку состояния. Полировать типографику, ритм отступов и визуальный контраст уже существующих `ttk`-стилей; не перестраивать окно и не менять конвертер. Использовать текущую палитру как основу, добавляя только необходимые акценты и состояния фокуса/наведения.

## Документация и репозиторий

- Корневой README по-русски ведёт новичка к последнему GitHub Release, объясняет скачивание и запуск готового Windows `.exe`, SmartScreen, открытие шрифта, конвертацию и расположение результата. CLI/форматы/разработка остаются ниже.
- Сохранить подробные технические сведения о контейнере; при необходимости вынести их в `docs/format.md` с корректным UTF-8.
- Обновить `docs/screenshot.jpg` на снимок текущего GUI с синтетическим примером, без личных путей.
- Сохранить MIT `LICENSE` и upstream-атрибуцию `claudessh`.
- Удалить исторические fallback-пути из smoke-режима; пользовательские корпуса проверяются явными CLI-аргументами.
- Исключить реальные личные `.gfont` из AyuGram-папки из чистого снимка; заменить их использование в тестах синтетическими V5/V8/V9-контейнерами, сохранив размеры наборов и проверки предупреждений.
- Не добавлять пользовательские `.gfont`, временные файлы, кэши или новые сборочные артефакты, кроме целевого exe в `dist/`.
- Репозиторий `Ka1nnnn/gfont-converter` оставлять публичным по явному запросу владельца; отправлять изменения только после проверки дерева/истории и артефакта на секреты.
- Публиковать актуальное дерево отдельным корневым коммитом: исходная история содержит машинно-локальные абсолютные пути, не нужные в удалённом репозитории.
- Выпустить tag/release `v1.1.1` с `dist/GFontConverter.exe` как asset. Сверить SHA-256 загруженного asset с локальной проверенной сборкой и дождаться зелёной GitHub Actions.

## Проверки

- Pytest и Ruff по командам проекта.
- Layout-проверки сравнивают ширину центральной сетки с шириной боковых панелей, не предполагая конкретное разрешение runner.
- Сборка PyInstaller, запись SHA-256 `dist/GFontConverter.exe`, проверка упакованных `--smoke` и `--convert`.
- Gitleaks по рабочему дереву и всей Git-истории, перед push; секреты в отчётах редактировать на 100%.
- Проверить `git status` и diff до commit/push; не менять пользовательские или сторонние репозитории.
