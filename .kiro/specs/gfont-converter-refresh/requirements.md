# GFont Converter — UI, документация и публичный релиз

## Цель

Немного освежить подтверждённую версию GFont Converter v1.1.0, найденную в локальном Git-репозитории, подготовить понятную русскую страницу проекта и выпустить публичный Windows-релиз в GitHub.

## Границы

- Источник для изменений — подтверждённый локальный Git-проект; его `dist\GFontConverter.exe` побайтно совпадал с exe на рабочем столе.
- Изменения UI остаются косметическими: не менять форматы, конвертацию, разбор файлов и основные сценарии.
- Сохранять Tkinter и стандартную библиотеку; новые runtime-зависимости не добавлять.
- Сохранять MIT-лицензию и атрибуцию автора `claudessh`.
- GitHub-репозиторий публичный по прямому запросу владельца.
- Не включать личные пути, временные скриншоты, ключи или пользовательские шрифты в новые материалы.

## Требования

### FR

- **FR-1**: UI SHALL сохранить тёмную тему и текущие действия, но получить заметную полировку отступов, иерархии и состояний элементов.
- **FR-2**: README SHALL на русском объяснять назначение и давать новичку пошаговую инструкцию: открыть страницу последнего релиза, скачать `GFontConverter.exe`, запустить без установки/Python, открыть `.gfont`, найти глиф, конвертировать и найти результат. Продвинутые сведения (CLI, сборка, версии и ограничения) остаются ниже.
- **FR-3**: Скриншот README SHALL соответствовать обновлённому интерфейсу и использовать безопасный пример без пользовательского пути/имени шрифта.
- **FR-4**: До push SHALL пройти проверка истории и текущего дерева Gitleaks с полностью редактированными отчётами.
- **FR-5**: GitHub-репозиторий SHALL быть публичным, сохранять MIT-лицензию, сведения об авторстве и понятную структуру.
- **FR-6**: Собранный `dist\GFontConverter.exe` SHALL соответствовать обновлённому исходнику.
- **FR-7**: Исходник и новые материалы SHALL не содержать пользовательских абсолютных путей; smoke-режим по умолчанию проверяет комплектные fixtures, а дополнительные файлы принимаются только явными аргументами.
- **FR-8**: Опубликованный снимок SHALL исключить личные шрифты из папки AyuGram; связанные регрессионные тесты SHALL собирать воспроизводимые synthetic-контейнеры.
- **FR-9**: GitHub SHALL содержать релиз `v1.1.1` с проверенным `GFontConverter.exe` как скачиваемым asset.
- **FR-10**: Перед релизом SHALL быть проверены секреты в публикуемом репозитории и остальных доступных репозиториях владельца; секретные значения не должны появляться в отчётах.

### NFR

- **NFR-1**: Поведение конвертера и выходные файлы остаются неизменными.
- **NFR-2**: Интерфейс сохраняет работу при минимальном размере окна и масштабировании Windows.
- **NFR-3**: Документация не обещает неподтверждённых возможностей и различает V0/V3/V5/V6/V7/V8/V9.
- **NFR-4**: Проверки компоновки GUI SHALL учитывать ограничения виртуального экрана Windows runner и проверять относительное распределение доступного места.

## Критерии приёмки

**Статус:** завершено; репозиторий публичный, README ведёт новичка к скачиванию, релиз `v1.1.1` опубликован, SHA-256 asset совпадает с проверенной локальной сборкой, GitHub Actions зелёные.

- **AC-1**: В diff нет изменений алгоритмов конвертации/парсинга и форматов файлов.
- **AC-2**: Русский README даёт новичку короткие проверяемые шаги скачивания и запуска без Python, объясняет SmartScreen, открытие файла, конвертацию и место результата; технические инструкции доступны ниже.
- **AC-3**: Обновлённый скриншот не показывает пользовательский локальный путь или личный файл.
- **AC-4**: Pytest, Ruff, сборка PyInstaller и локальные Gitleaks-сканы завершаются без ошибок.
- **AC-5**: Репозиторий `Ka1nnnn/gfont-converter` имеет видимость public; `origin/main` совпадает с локальной веткой.
- **AC-6**: Ни значение обнаруженного в стороннем репозитории/локальном логе ключеподобного совпадения, ни секретные значения не попадают в отчёт.
- **AC-7**: В diff и публикуемом дереве нет локальных абсолютных путей; `--smoke` продолжает работать по комплектным fixtures.
- **AC-8**: Ни один файл из `tests/fixtures/ayugram/` не включён в публикуемый снимок; pytest покрывает эти регрессии synthetic-данными.
- **AC-9**: Проверка ширины сетки глифов проходит при минимальной ширине окна на небольшом виртуальном экране, сохраняя сетку шире боковых панелей.
- **AC-10**: Последний GitHub Release — `v1.1.1`, содержит `GFontConverter.exe`; скачанный asset совпадает с проверенной локальной сборкой по SHA-256.
- **AC-11**: GitHub Actions для тега релиза проходит успешно.
- **AC-12**: История и рабочее дерево этого проекта и доступные репозитории владельца просканированы; найденные подозрительные совпадения сообщены без раскрытия значений.
