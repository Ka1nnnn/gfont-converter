# Справка по формату `.gfont`

Этот документ описывает версии, которые читает GFont Converter. Парсер остаётся источником истины для точной валидации и нормализации.

## Кратко по версиям

| Версия | Метаданные | Данные глифов |
| --- | --- | --- |
| V0 | Нет | ZIP с сырыми KDraw-блоками |
| V3 | Открытые | Запись глифа с кодом BMP-символа |
| V5 / V6 / V7 | TEA-зашифрованы | Запись глифа старого типа |
| V8 | TEA-зашифрованы | UTF-8 код символа и несколько контуров |
| V9 | TEA-зашифрованы | Сырые KDraw-блоки |

Чтение поддерживает V0, V3, V5, V6, V7, V8 и V9. Запись поддерживает только V3 и V5.

## Контейнер

Для V3/V5/V6/V7/V8/V9 файл начинается с номера версии (`int32`, big-endian), затем содержит метаданные, блок предпросмотра и ZIP-архив глифов. V0 — ZIP без внешнего заголовка и метаданных.

Метаданные содержат имя/автора (`e`), тип пера (`q`), флаги (`b`, `a`), язык или стиль (`c`), размер шрифта, объявленное число глифов (`glyph_count`) и дополнительные поля (`n`, `o`). В V3 метаданные открытые; в V5 и более новых версиях блок зашифрован.

Блок предпросмотра хранит до 30 глифов. Затем идёт ZIP: имя каждой записи — десятичный код символа, а содержимое зависит от версии. В V0 и V9 это сырые данные KDraw; в V8 — многоконтурная запись; в V3/V5/V6/V7 — запись старого типа.

## Записи глифов

В старой записи хранятся код BMP-символа, количество координат, пары `float32` (X/Y, big-endian), количество команд и массив команд. Команда `0` начинает штрих («перо поднято»), `1` соединяет точку с предыдущей («перо опущено»). Координата Y направлена вниз.

V8 хранит один или несколько контуров для глифа. Код символа задаётся UTF-8 и может быть вне BMP; первый контур содержит код, последующие продолжают геометрию. При записи V3/V5 символы выше `U+FFFF` пропускаются: эти версии используют код BMP-символа.

## Предупреждения и ограничения

- Если `glyph_count` в метаданных расходится с количеством ZIP-записей, используются фактические записи; несоответствие попадает в журнал.
- Счётчик предпросмотра ограничен 30 глифами; при записи сохраняются до 30 крупных глифов.
- Неизвестный тип пера сохраняется как есть и показывается в метаданных.
- Лишние байты после метаданных или перед ZIP могут быть приняты с предупреждением, если ZIP-структура найдена.
- Контур V8, начинающийся с опущенного пера, нормализуется так, чтобы контуры оставались раздельными.
- Команда `2` (точка Безье) при просмотре приближается отрезком.
- Ограничения защиты парсера: до 32 МиБ на диске, 64 МиБ после распаковки, 16 384 ZIP-записей и 2 000 000 точек.
- Повреждённые ZIP-структуры, усечённые записи, некорректные числа и координаты NaN отклоняются.
